# ルート最適化アプリ

家電修理などの現場をまわるフィールドエンジニア向けに、**1日の訪問ルートを最短化・見える化** するWebアプリです。住所メモを貼り付けるだけでAIが訪問先を抽出し、Google Mapsで最適なルートを計算。アナログ時計風のスケジュール表で1日の流れがひと目で分かります。

スマホでもPCでも使えます。ブラウザだけで動くので、インストール不要です。

## できること

- **訪問先のかんたん入力**
  - クライアントから届いたテキスト・スクショ画像を貼り付けると、AIが住所・作業メモ・指定時間を抽出
  - 個人名は読み取らずに破棄（プライバシー保護）
  - 手動入力ももちろん可能、最大15件まで登録
- **3つの最適化案＋カスタム**
  - **最短**：総移動時間が一番短いルート
  - **余裕**：指定時間の中央を狙う安定重視のルート
  - **確実**：難しい案件を朝に固めて午後を楽にするルート
  - **カスタム**：上下ボタンで手動並び替え。指定時間に違反する手順は事前に赤く警告
- **クロック型スケジュール表**
  - アナログ時計の文字盤に1日のスケジュールを色分け描画
  - 移動（青）／作業（緑/黄/赤＝難易度別）／準備・撤収（薄色）／昼休憩（オレンジ）／空き時間（グレー）
  - 訪問先の指定時間（以前 / 以降 / 範囲）も内周にレイヤー表示
- **ランチ候補の自動提案**
  - 設定したお気に入りチェーン（マック・吉野家・松屋・コンビニ等）から、ルート中盤に近い店舗を最大5件提案
- **地図表示**
  - 行政区域（薄色）／標準／航空写真の3モード切替
  - 訪問先ピンは難易度色＋順番、ルートは矢印つき青ライン
  - すべてのピンが収まる適度な余白で自動ズーム
- **Google Mapsでナビ開始**
  - ワンタップで本物のGoogle Mapsアプリにルートを引き継ぎ
- **本日の進捗追跡**
  - 各訪問の完了チェックで「3件中1件完了」を表示

## 使い方

1. **デモを開く**：[GitHub Pagesで試す](https://165cm.github.io/field-engineer-route-optimizer/)
2. **起点・終点・出発時刻を編集**（カード右上の「編集」）
3. **訪問先を追加**：
   - メール本文をコピー → AI一括入力 にペースト
   - またはカメラ／画像から伝票を読み取り
   - 手動の場合は「訪問先を追加」
4. **作業内容と難易度（低／中／高）を選択**、必要なら **指定時間（以前／以降／範囲）** を設定
5. **「ルートを計算」をタップ**
6. 結果画面で **最短／余裕／確実** を比べる、または **カスタム** で並び替え
7. **「Google Maps でナビ開始」** で実走へ

> ⓘ AI解析機能はデモ環境では1日10回の上限があり、初回利用時にパスワード入力を求められます。
