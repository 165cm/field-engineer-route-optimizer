# ルート最適化アプリ ![Tier](https://img.shields.io/badge/tier-T2-blue)

> 訪問先を「まわりやすい順」に自動で組み立て

## これは何？

フィールドエンジニア向けの訪問ルート最適化アプリです。複数の訪問先を入力すると、移動時間・作業時間・時間指定をもとに、まわりやすい順番と到着予定時刻を自動で組み立てます。Google Mapsでそのままナビを開始できるので、朝の段取りや移動中の再確認に使いやすい設計です。

## こんな時に使えます

- 1日に複数件の訪問があるフィールドエンジニア
- 家電修理・点検・設置などで移動と作業時間をまとめて管理したい人
- 訪問順を毎朝考える時間を減らしたい人
- Google Mapsでナビはしたいが、事前のルート整理は別で行いたい人

## 使い方

- 🌐 デモ: https://165cm.github.io/field-engineer-route-optimizer/

1. **起点・終点・作業日・出発時刻を設定** — 自宅や事務所など出発場所を設定。終点は「起点に戻る」「別住所」「最終訪問先で終了」から選択。Googleカレンダーへ登録する場合は、ここで作業日も確認します。
2. **訪問先を追加** — 住所・作業内容・滞在時間・時間指定を入力。AIで、メール文面や画像から候補を作ることもできます。
3. **休憩時間を設定** — ランチ・休憩時間を 0〜60分 の範囲で設定。
4. **ルートを計算** — 複数のルート案とおすすめスコア・到着予定時刻が表示されます。
5. **Google Mapsでナビ開始** — 作成した訪問順をそのまま Google Maps に渡して移動開始。
6. **Googleカレンダーに一括登録** — ルート計算後の結果画面下部にある「Googleカレンダーに一括登録」ボタンから、選択中のルート案の現地滞在予定を1日分まとめて登録できます。初回だけGoogleログインと権限許可が必要です。

### Googleカレンダー登録ボタンが見当たらない時

- ボタンは、訪問先を入力して **「ルートを計算」した後の結果画面下部** に表示されます。入力画面には表示されません。
- Google Mapsの「ナビ開始」ボタンの下に表示されます。画面が小さい場合は、結果画面を下までスクロールしてください。
- `GOOGLE_CALENDAR_CLIENT_ID` が未設定の環境では、直接登録は使えず「Google連携は未設定」と表示されます。その場合は、下の「Googleカレンダー用に1日分を書き出す」からICSファイルを書き出して利用してください。
- GitHub Pagesでは、`GOOGLE_CALENDAR_CLIENT_ID` を GitHub Actions の **Repository secrets** または **Repository variables** に登録してから、Pagesを再デプロイしてください。
- カレンダーに登録されるのは、到着時刻から撤収後の終了時刻までの **現地滞在予定** です。顧客名・電話番号・詳細な作業メモは登録しません。

## 主な機能

- **訪問先をまとめて管理** — 住所・作業内容・滞在時間・時間指定を1画面で整理
- **タスクのインライン編集** — リスト上でタスク名・作業時間をその場で直接変更
- **住所の事前チェック** — 入力した住所が地図で見つかるかその場で確認。ルート計算が失敗した時も、どの訪問先の住所が原因かを特定して表示
- **履歴からの住所オートコンプリート** — 住所入力中に過去の訪問先から候補を表示。よく使う訪問先はピン留めして「お気に入り」に固定
- **削除の取り消し** — 訪問先やリセット、履歴の削除は「元に戻す」ボタンでその場で復元
- **カスタム案のドラッグ並び替え** — カスタムルートは上下ボタンに加えてドラッグ&ドロップでも順番変更
- **モバイルで地図を表示切替** — スマホでは結果画面の地図を折りたたんでタイムラインに集中できる
- **効率のよい巡回順を提案** — 移動時間や距離をもとに複数のルート案を作成
- **おすすめ案を100点満点で表示** — 移動時間・距離・時間指定の余裕をスコア化
- **作業時間込みで予定を見える化** — 準備15分・作業・撤収15分を含めたタイムライン
- **ルートの鮮度チェック** — 訪問先や設定を変更すると警告バナーで再計算を促す
- **休憩時間をかんたん挿入** — 15分単位、最大60分をルート中盤に挿入
- **Google Mapsでナビ開始** — 訪問順をそのままGoogle Mapsへ渡して移動
- **Googleカレンダーに一括登録** — 選択中のルート案を、現地滞在予定としてGoogleカレンダーへまとめて登録
- **AIで入力を補助** — メール文面や画像から住所・時間指定・難易度を読み取り、確認画面で作業時間も調整可能

## 大切な考え方

このアプリは顧客情報の管理アプリではありません。個人情報保護のため、顧客名や詳細な作業メモではなく、住所・時間指定・作業時間・ルート管理に集中しています。

## 注意点

- ルートや到着時刻は Google Maps の移動時間をもとにした目安です。渋滞・駐車・入館・現地対応の遅れは別途考慮してください。
- Google Maps で開いた後は、必ず表示された訪問先と順番を確認してください。
- AI読み取り結果は必ず確認してから登録してください。住所の誤読があるとルートもずれます。
