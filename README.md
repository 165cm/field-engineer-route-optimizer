# ルート最適化アプリ

現場をまわる仕事のための、訪問ルートと時間管理アプリです。

複数の訪問先を入力すると、移動時間・作業時間・時間指定をもとに、まわりやすい順番と到着予定時刻を自動で組み立てます。Google Mapsでそのままナビを開始できるので、朝の段取りや移動中の再確認に使いやすい設計です。

## このアプリでできること

- **訪問先をまとめて管理**
  住所、作業内容、滞在予定時間、時間指定を1画面で整理できます。
- **効率のよい巡回順を提案**
  移動時間や距離をもとに、複数のルート案を作ります。
- **おすすめ案を100点満点で表示**
  移動時間、距離、時間指定への余裕をもとに、どの案が使いやすいかを数値で確認できます。
- **作業時間込みで予定を見える化**
  準備15分、作業時間、撤収15分を含めて、到着から完了までの流れを表示します。
- **休憩時間をかんたん挿入**
  ランチや休憩を15分単位、最大60分までルート中盤に入れられます。
- **Google Mapsでナビ開始**
  作成した訪問順をGoogle Mapsに渡して、そのまま移動に使えます。
- **AIで入力を補助**
  メール文面や画像から、住所・時間指定・難易度を読み取って訪問先候補を作れます。

## 向いている人

- 1日に複数件の訪問があるフィールドエンジニア
- 家電修理、点検、設置などで移動と作業時間をまとめて管理したい人
- 訪問順を毎朝考える時間を減らしたい人
- Google Mapsでナビはしたいが、事前のルート整理は別で行いたい人

## 基本的な使い方

1. **起点・終点・出発時刻を設定**
   自宅、事務所、現在地など、出発場所を設定します。終点は「起点に戻る」「別住所」「最終訪問先で終了」から選べます。

2. **訪問先を追加**
   住所、作業内容、滞在予定時間、時間指定を入力します。AI読み取りを使うと、メール本文や画像から候補を作れます。

3. **休憩時間を設定**
   必要に応じて、ランチ・休憩時間を「なし / 15分 / 30分 / 45分 / 60分」から選びます。

4. **ルートを計算**
   複数のルート案と、おすすめスコア、到着予定、作業完了予定が表示されます。

5. **Google Mapsでナビ開始**
   訪問順をGoogle Mapsへ渡して、移動を開始します。

## 画面で見るポイント

- **おすすめ案**
  迷ったらまずここを見ます。100点に近いほど、移動・距離・時間指定のバランスがよい案です。

- **タイムライン**
  各訪問先の到着時刻、作業完了時刻、時間指定への余裕を確認できます。

- **時計表示**
  1日の流れをざっくり把握できます。移動、作業、休憩、空き時間が色分けされます。

- **地図**
  訪問順とルートの方向を地図上で確認できます。

## 大切な考え方

このアプリは、顧客情報の管理アプリではありません。

個人情報保護のため、顧客名や作業メモの保存ではなく、住所・時間指定・作業時間・ルート管理に集中しています。詳しい作業メモや顧客情報は、業務用端末や既存の管理システムで扱う想定です。

## 注意点

- ルートや到着時刻は、Google Mapsの移動時間をもとにした目安です。
- 渋滞、駐車、入館、現地対応の遅れは別途考慮してください。
- Google Mapsで開いた後は、必ず表示された訪問先と順番を確認してください。
- AI読み取り結果は必ず確認してから登録してください。住所の誤読があるとルートもずれます。
